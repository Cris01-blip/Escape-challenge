Desafío de Escape

Proyecto web de un juego de escape

Mi idea es crear un juego de escape con diferentes niveles, acertijos y pistas. El jugador tendrá que resolver cada desafío para poder avanzar al siguiente nivel.

Características del proyecto

  • Varios niveles
  • Acertijos y desafíos
  • Pistas para ayudar al jugador
  • Sistema para avanzar entre niveles
  • Diseño interactivo utilizando React
